# Atlanta UI Library

Updated Atlanta UI library with responsive scaling, adjustable UI size, improved window dragging, and always-visible tooltips.

## Loader

```lua
local library, themes = loadstring(game:HttpGet(
    "https://raw.githubusercontent.com/Financially/ui-lib/refs/heads/main/Atlanta/Library.lua"
))()
```

## Example

See [`Atlanta/Example.lua`](Atlanta/Example.lua) for a complete setup.

## UI scaling

The initial scale is selected automatically for the current viewport. It can be changed from the **Style** panel using the **UI Scale** slider.

The slider supports values from 60% to 110%.
